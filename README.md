# Tic-Tac-Toe-game
This is a simple Tic Tac Toe game made using HTML, CSS, and JavaScript. 
It is a two-player game where one player plays with O and the other with X.
Players click on the boxes to make their move, and the game automatically checks for a winner.

When a player wins, a message is shown on the screen with the winner’s name.
There is also a Reset Game and New Game button to restart the game anytime.
